# 搜 · 打 · 撤（Search · Fight · Extract）

> 一款运行在终端里的单机撤离射击（Extraction Shooter）小游戏。搜刮物资、对抗敌人、活着撤离——装备与战利品只在你成功撤离时才真正属于你。
>
> 🤖 推理模型：[DeepSeek V4.1 Flash](https://www.deepseek.com/news/deepseek-v4-1-flash/)
> 🛠️ 代理框架：[ManualAid](https://github.com/SunYanbox/ManualAid-Rust)

---

## 🎮 游戏特色

- **风险与回报**：背包里的每一件战利品，都要活着撤离才算到手；阵亡则背包、武器、护甲、消耗品尽失。
- **主被动双技能体系**：被动（8 种）与主动（7 种）分开选择，技能上限随部门等级提升。
- **五档难度**：D / C / B / A / S / SS，敌人的护甲与子弹等级、血量、攻击、爆率随难度动态变化。
- **RPG 成长**：用搜刮物资升级「天赋 / 主动技能 / 战斗 / 生存」四大部门，形成长期 Build。
- **完整经济循环**：搜刮 → 分解 → 生产 → 升级，战利品可出售换钱，也可分解成材料。
- **终端彩色 UI**：伤害、治疗、护甲、护盾、额外回合等均以 ANSI 颜色区分，状态一目了然。

## 🕹️ 核心玩法

一局流程：**潜入 → 搜索物资 → 遭遇战斗 → 找到撤离点 → 撤离**。

- **地图**：每局随机生成 10\~14 个区域，通过邻接关系连通，撤离点隐藏在随机位置。
- **探索**：未知区域显示为 `*`，进入后才揭示名称。探索超过 70% 区域后，即使未发现撤离点也可直接寻路前往。
- **战斗**：回合制。可选择开火、使用消耗品、释放主动技能或尝试脱离。
- **背包**：有重量上限，拾取时若超重会按「性价比」自动判断是否替换丢弃。

## ⚔️ 技能系统

技能分为**被动**与**主动**两类，出战前分别选择。

### 被动技能

| 技能 | 效果 |
|------|------|
| 超载 | 受伤 -10%，每 2 回合额外攻击一次且伤害 +25% |
| 蜂医 | 移动恢复 30 生命，并获得生命上限 45% 的护盾（可叠加，至多 3 层） |
| 深蓝 | 受到的所有伤害 -30% |
| 铁壁 | 护甲损耗 -40%，护甲上限 +20%；护甲破碎时获得 80% 免伤，持续 2 回合 |
| 拾荒者 | 搜索时额外获得 1 件物资 |
| 疾步 | 移动遭遇敌人的概率减半 |
| 乌云乌云快走开 | 生命上限 +200%，但护甲消耗速率翻倍 |
| 再现 | 累计（生命伤害 + 30%×护甲伤害）每满 50，下回合获得一个插入式额外行动（不消耗回合） |

### 主动技能

| 技能 | 效果 | 冷却 |
|------|------|------|
| 应急护盾 | 获得 120 点护盾 + 80 点临时护甲（按六级甲结算，每回合衰减 20） | 6 |
| 威龙 | 60 真实伤害 + 60 伤害（按 7 级弹穿透）；敌人生命 <70% 时伤害 +75% | 4 |
| 深蓝刺网 | 60 伤害（按 7 级弹穿透）并束缚敌人；敌人【受伤】3 回合，受到伤害 +20%（不叠加） | 5 |
| 快速射击 | 立即打出三段攻击（100% + 70% + 70%） | 3 |
| 应急治疗 | 立即恢复 60 生命 | 6 |
| 肾上腺素 | 清除所有主动技能冷却（不消耗回合） | 10 |
| 燃烧弹 | 75 伤害（按 7 级弹穿透）+ 每回合 15 燃烧（可被护甲抵御）+ 敌人灭火跳过一回合 | 4 |

> 所有主动技能伤害均按 **7 级子弹**的穿透规则结算。

## 🎯 难度设定

| 难度 | 敌人护甲/子弹 | 生命 | 攻击 | 护甲 | 爆率 |
|------|--------------|------|------|------|------|
| D | 1\~2 套 / 1 弹 | ×0.7 | ×0.8 | ×1.0 | 降低 |
| C | 1\~4 套 / 1\~3 弹 | ×1.0 | ×1.0 | ×1.0 | 标准 |
| B | 3\~5 套 / 2\~4 弹 | ×1.3 | ×1.1 | ×1.1 | 提升 |
| A | 4\~5 套 / 3\~5 弹 | ×1.6 | ×1.2 | ×1.2 | 大幅提升 |
| S | 4\~5 套 / 4\~5 弹 | ×1.9 | ×1.3 | ×1.3 | 巨量提升 |
| **SS** | 4\~5 套 / 4\~5 弹 | ×2.3 | ×1.4 | ×1.4 | 极高，且本局背包容量 +20% |

## 🏛️ 部门系统（RPG 成长）

用分解战利品获得的**材料**或**资金**升级四大部门：

| 部门 | 效果 | 上限 |
|------|------|------|
| 天赋 | 被动技能上限 2 / 3 / 4 | 3 |
| 主动技能 | 主动技能上限 2 / 3 / 4 | 3 |
| 战斗 | 伤害 +5/10/15/20/25%；Lv3+ 吸血 5/10%；Lv5 额外护甲回复 10% | 5 |
| 生存 | 生命 +5/10/15/20/25%；Lv3+ 护甲损耗 -5/10/15% | 5 |

> 升级消耗：Lv1 用资金，Lv2+ 用材料，均按指数增长。

## 💰 经济与装备

- **消耗品**：急救包、装备维修套件、肾上腺素。出击前可自选携带数量（撤离归还剩余，阵亡丢失）。
- **装备槽位**：武器、护甲、**胸挂**、**背包**——后两者提供额外背包容量。
- **武器与护甲**：子弹 1\~7 级、护甲 1\~6 级，越高等级穿透/防护越强。
- **经济循环**：
  ```
  搜刮战利品 → 仓库
     ├─ 装备 → 出售 / 装备
     ├─ 物资 → 分解 → 材料
     └─ 材料 + 资金 → 生产消耗品 / 升级部门
  ```
- **生产车间**：用材料 + 少量资金，一次性生产多个消耗品。

## 🧮 伤害与乘区规则

所有同类加成**加算**后再参与最终计算：

```
生命上限   = 100 × (1 + 生存生命加成 + 乌云 200%)
造成伤害   = 基础攻击 × 技能倍率 × (1 + 战斗部门 + 受伤 + 威龙条件)
护甲损耗   = 1 - (生存减免 + 铁壁 40%) + 乌云 100%，最低 0.1
```

穿透规则：高弹打低甲（100% 伤害 / 甲吸 30%）、同级（75% / 50%）、低弹打高甲（50% / 80%）。

## 🚀 运行

环境要求：**.NET 10 SDK**

```bash
# 克隆仓库
git clone <repo-url>
cd SDC

# 运行
dotnet run

# 或构建后运行
dotnet build
dotnet bin/Debug/net10.0/SearchFightExtract.dll
```

### 存档

- 存档位于 `saves/名字.json`，**支持中文命名**。
- 启动时进入存档选择界面：可载入、新建（`n`）、删除（`d`）存档。
- 选择页面会显示每个存档的**资金、材料与四部门等级**。
